### Теоретические основы

Для выполнения данной лабораторной работы выбраны 2 утилиты: **GPU-Z v0.6.0** и **FurMark v1.10.2**. GPU-Z выдает информацию о видеокарте, а FurMark проводит тестирование.

*   **GPU-Z** — это программа для вывода информации о графическом адаптере, которая поддерживает карты NVIDIA и ATI. Она помогает узнать модель видеокарты, интерфейс подключения, информацию о графическом процессоре (версия BIOS, номер ревизии чипа, частота в 2D, 3D-режимах и при разгоне, сведения о поддержке DirectX). Также GPU-Z предоставляет информацию о видеопамяти: тип, объем, разрядность шины.

### Контрольные вопросы

#### 1. Какие другие программы используют для тестирования видеокарт?

Помимо упомянутых GPU-Z и FurMark, для тестирования видеокарт существует множество специализированных утилит. Их можно разделить на категории.

**Информационно-диагностические:**
*   **GPU Caps Viewer** (от автора FurMark): предоставляет подробные отчеты о поддержке графических API (OpenGL, OpenCL, CUDA).
*   **HWiNFO**: мощный инструмент для мониторинга до 30 параметров видеокарты в реальном времени (температуры, частоты, напряжения).

**Стресс-тестирование:**
*   **MSI Kombustor**: утилита для максимальной нагрузки GPU и выявления слабых мест системы охлаждения.
*   **OCCT**: программа для комплексных стресс-тестов GPU, блока питания и видеопамяти.
*   **Video Memory Stress Test**: узкоспециализированная утилита для выявления ошибок в видеопамяти.

**Бенчмарки (оценка производительности):**
*   **3DMark**: промышленный стандарт для тестирования игровой производительности (тесты DirectX 12, трассировки лучей).
*   **Unigine Superposition / Heaven Benchmark**: создают сложные 3D-сцены для оценки производительности и стабильности в условиях, приближенных к реальным играм.
*   **Basemark GPU**: инструмент для тестирования современных технологий (Vulkan, аппаратное ускорение трассировки лучей).

#### 2. Какие программы используют для тестирования мониторов?

Для проверки качества и настройки мониторов существуют специализированные утилиты для выявления битых пикселей, оценки равномерности подсветки и цветопередачи.

*   **DisplayHDR Test**: программа от VESA для тестирования яркости, контрастности и цветового охвата HDR и SDR мониторов.
*   **MonitorTest** (PassMark Software): утилита для оценки качества любых типов экранов с использованием специальных тестовых шаблонов.
*   **Screentest**: консольная утилита для Linux, выводящая набор тестовых экранных шаблонов для быстрой оценки качества монитора.
*   **Monitor Test Tool**: универсальный инструмент, включающий тесты на битые пиксели, равномерность подсветки, цветовые градиенты, время отклика и гамму.
