
# Лабораторная работа "Основные команды ОС GNU/LINUX"

## Основные команды оболочки операционной системы GNU/Linux — работа с файлами и каталогами

### Цель занятия
Ознакомиться с имеющимися в операционной системе GNU/Linux командами оболочки для работы с файлами и каталогами.

### Изучаемые основные навыки
1. Навигация по каталогам файловой системы и просмотр списка файлов и каталогов.
2. Создание и удаление файлов и каталогов в файловой системе.
3. Копирование и перемещение файлов в файловой системе.
4. Копирование и перемещение каталогов в файловой системе.
5. Использование шаблонов при работе с файлами и каталогами.
6. Поиск файлов и каталогов.
7. Создание и использование ссылок на файлы и каталоги.
8. Оценка занятого и свободного пространства.

## Задание

### 1. Навигация по каталогам файловой системы и просмотр списка файлов и каталогов

**Действия:**

```bash
# Вывод пути текущего каталога
pwd

# Вывод списка файлов текущего каталога
ls

# Вывод списка всех объектов (включая скрытые) текущего каталога
ls -a

# Переход в каталог /bin
cd /bin

# Вывод длинного списка объектов в текущем каталоге
ls -l

# Вывод длинного списка объектов в каталоге /sbin
ls -l /sbin

# Переход в домашний каталог пользователя (без аргументов)
cd

# Переход в домашний каталог пользователя (с тильдой)
cd ~

# Переход в каталог /tmp
cd /tmp
```

### 2. Создание и удаление файлов и каталогов в файловой системе

**Действия:**

```bash
# Создание нового каталога newdir в /tmp
mkdir newdir

# Проверка успешности создания
ls -d /tmp/newdir

# Удаление пустого каталога newdir
rmdir newdir

# Проверка успешности удаления
ls -d /tmp/newdir

# Создание пары вложенных каталогов newdir1/newdir2
mkdir -p newdir1/newdir2

# Проверка успешности создания
ls -d /tmp/newdir1/newdir2

# Удаление пары вложенных каталогов
rmdir -p newdir1/newdir2

# Проверка успешности удаления
ls -d /tmp/newdir1/newdir2

# Создание нового файла newfile1
touch newfile1

# Проверка успешности создания
ls -l /tmp/newfile1

# Создание файла newfile2 с помощью перенаправления вывода
> newfile2

# Проверка успешности создания
ls -l /tmp/newfile2

# Удаление файла newfile2
rm newfile2

# Проверка успешности удаления
ls /tmp/newfile2
```

### 3. Копирование и перемещение файлов в файловой системе

**Действия:**

```bash
# Копирование файла /etc/fstab в каталог /tmp
cp /etc/fstab /tmp

# Проверка успешности копирования
ls -l /tmp/fstab

# Получение информации об исходном файле и копии
ls -l /etc/fstab

# Копирование файла /etc/passwd с сохранением временных атрибутов
cp -p /etc/passwd /tmp

# Проверка успешности копирования (сравнение атрибутов)
ls -l /etc/passwd
ls -l /tmp/passwd

# Перемещение файла /tmp/fstab под именем /tmp/fstab_new
mv /tmp/fstab /tmp/fstab_new

# Проверка успешности перемещения
ls /tmp/fstab /tmp/fstab_new
```

### 4. Копирование и перемещение каталогов в файловой системе

**Действия:**

```bash
# Создание пары вложенных каталогов dir_a/dir_b
mkdir -p dir_a/dir_b

# Копирование каталога dir_a рекурсивно в dir_a_copy
cp -r dir_a dir_a_copy

# Проверка успешности копирования
ls -l /tmp/dir_a_copy

# Получение информации об исходном каталоге
ls -l /tmp/dir_a

# Копирование каталога dir_a рекурсивно с сохранением атрибутов
cp -ra dir_a dir_a_copy2

# Проверка успешности копирования
ls -l /tmp/dir_a_copy2

# Перемещение каталога dir_a в dir_a_new
mv /tmp/dir_a /tmp/dir_a_new

# Проверка успешности перемещения
ls -la /tmp/dir_a_new
```

### 5. Использование шаблонов при работе с файлами и каталогами

**Действия:**

```bash
# Создание нескольких файлов с похожими именами
touch file1 file2 file3 file4

# Вывод списка файлов, имена которых начинаются с file
ls -l file*

# Удаление всех файлов, имена которых начинаются с file
rm file*

# Проверка успешности удаления
ls -l file*
```

### 6. Поиск файлов и каталогов

**Действия:**

```bash
# Поиск файла .bashrc в домашнем каталоге
find ~ -name '.bashrc'

# Поиск всех файлов .png в домашнем каталоге
find ~ -name '*.png'

# Поиск каталогов с именем Pictures в домашнем каталоге
find ~ -name 'Pictures'
```

### 7. Создание и использование ссылок на файлы и каталоги

**Действия:**

```bash
# Создание символической ссылки на файл /etc/fstab
ln -s /etc/fstab fstab_link

# Проверка успешности создания ссылки
ls -l fstab_link

# Создание символической ссылки на каталог /etc
ln -s /etc etc_link

# Проверка успешности создания ссылки
ls -ld etc_link

# Создание нового файла и символической ссылки на него
touch new_file
ln -s new_file new_file_link

# Проверка успешности создания ссылки
ls -l new_file_link

# Удаление исходного файла и проверка состояния ссылки
rm new_file
ls -l new_file_link
# Примечание: ссылка становится "мертвой" (broken)
```

### 8. Оценка занятого и свободного пространства

**Действия:**

```bash
# Получение информации о занимаемом каталогом /etc месте
du -sh /etc

# Получение информации о занимаемом каталогом /usr месте (в интерактивном режиме)
ncdu /usr

# Получение информации об использовании дискового пространства
df -h
```

## Контрольные вопросы

**1. Какую команду необходимо использовать для вывода текущего каталога?**
`pwd`

**2. Какую команду необходимо использовать для вывода содержимого каталога?**
`ls`

**3. Какую команду необходимо использовать для создания текущего каталога?**
`mkdir`

**4. Какую команду необходимо использовать для удаления каталога?**
`rmdir` (для пустого каталога) или `rm -r` (для непустого каталога)

**5. Какие команды необходимо использовать для удаления каталога?**
`rmdir` или `rm -r`

**6. Какие команды необходимо использовать для создания пустого файла?**
`touch` (или `> имя_файла` для перенаправления вывода)

**7. Как обозначается оператор перенаправления вывода?**
Символ `>`

**8. Какую команду необходимо использовать для копирования объектов?**
`cp`

**9. Какую команду необходимо использовать для перемещения объектов?**
`mv`

**10. Какую команду необходимо использовать для удаления объектов?**
`rm`

**11. Какую команду необходимо использовать для поиска объектов?**
`find`

**12. Какую команду необходимо использовать для создания нескольких ссылок?**
`ln` (с флагом `-s` для создания символических ссылок)

**13. Какую команду необходимо использовать для получения занимаемого каталогом дискового пространства?**
`du` (с флагом `-sh` для наглядного вывода)

**14. Какую команду необходимо использовать для отображения занимаемого дискового пространства в наглядном виде?**
`ncdu`

**15. Какую команду необходимо использовать для получения информации об использовании дискового пространства?**
`df` (с флагом `-h` для наглядного вывода)
`df -h`
