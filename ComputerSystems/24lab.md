## Краткие теоретические сведения

### Файловая структура системы LINUX
В операционной системе LINUX файлами считаются:
- обычные файлы,
- каталоги,
- специальные файлы, соответствующие периферийным устройствам (каждое устройство представлено в виде файла).

Доступ ко всем файлам однотипный, в том числе и к файлам периферийных устройств. Такой подход обеспечивает независимость программы пользователя от особенностей ввода/вывода на конкретное внешнее устройство.

Файловая структура LINUX имеет **иерархическую древовидную** структуру. В корневом каталоге размещаются другие каталоги и файлы, включая 5 основных:

| Каталог | Назначение |
|---------|-------------|
| `/bin`  | Большинство выполняемых командных программ и shell-процедур |
| `/tmp`  | Временные файлы |
| `/usr`  | Каталоги пользователей (условное обозначение) |
| `/etc`  | Административные утилиты и файлы |
| `/dev`  | Специальные файлы периферийных устройств |

**Текущий каталог** — каталог, в котором в данный момент находится пользователь. Обозначается одной точкой (`.`).  
**Родительский каталог** (тот, которому принадлежит текущий) обозначается двумя точками (`..`).

Полное имя файла может включать имена каталогов, разделённых косой чертой, например:  
`/home/student/file.txt`  
Первая косая черта обозначает корневой каталог, далее поиск идёт по вложенности.

### Связи (links)
Один файл можно сделать принадлежащим нескольким каталогам с помощью команды `ln`:
```bash
ln <имя файла 1> <имя файла 2>
```
- `<имя файла 1>` — полное имя файла, с которым устанавливается связь;
- `<имя файла 2>` — полное имя файла в новом каталоге, где будет использоваться эта связь.

Символическая связь создаётся с ключом `-s`:
```bash
ln -s <имя файла 1> <имя файла 2>
```
Здесь `<имя файла 2>` — имя символической ссылки, которая хранит путь к исходному файлу. При обращении к символической ссылке работа идёт с содержимым файла, на который она ссылается.

### Уровни доступа и атрибуты
В LINUX различаются **три уровня доступа** к файлам и каталогам:
1. Владелец файла (user);
2. Группа пользователей, к которой принадлежит владелец (group);
3. Остальные пользователи (others).

Для каждого уровня устанавливаются права, представленные символами:

| Символ | Значение |
|--------|----------|
| `r`    | Разрешение на чтение |
| `w`    | Разрешение на запись |
| `x`    | Разрешение на выполнение |
| `-`    | Отсутствие разрешения |

Первый символ в строке атрибутов определяет **тип файла**:

| Символ | Тип файла |
|--------|------------|
| `-`    | Обычный файл |
| `d`    | Каталог (директория) |
| `l`    | Символическая связь |
| `b`    | Блок-ориентированный специальный файл (дисковые накопители) |
| `c`    | Байт-ориентированный специальный файл (принтер, терминал) |

**Просмотр атрибутов** осуществляется командой `ls -l`. Формат вывода:
```
d rwx rwx rwx
│  └─┬─┘ └─┬─┘ └─┬─┘
│ влад. группа остальные
тип
```

**Пример вывода `ls -l`:**
```
-rwx------ 2 student 100 Mar 10 10:30 file_1
-rwxr----- 1 adm     200 May 20 11:15 file_2
-rwxr----- 1 student 100 May 20 12:50 file_3
```
Столбцы (слева направо): права доступа, число связей, владелец, размер в байтах, дата и время модификации, имя файла.

**Изменение прав доступа** выполняется командой `chmod`.  
Коды защиты можно задавать в символьном или числовом виде.

*Символьный формат:*
- `+` добавить права, `-` отменить права.
- `r`, `w`, `x` — чтение, запись, выполнение.
- `u` (владелец), `g` (группа), `o` (остальные).

Примеры:
```bash
chmod g+rw,o+r file.1   # добавить группе rw, остальным r
ls -l file.1            # проверить атрибуты
chmod o-w file.1        # отменить запись у остальных
```

*Числовой формат* (восьмеричный) — сумма битов:  
`r` = 4, `w` = 2, `x` = 1.  
Права задаются тремя цифрами для владельца, группы и остальных.

### Основные команды работы с файлами и каталогами

#### Создание и просмотр
```bash
> letter                 # создание пустого файла letter (через перенаправление)
cat letter               # вывод содержимого
cat file.1 file.2 > file.12   # объединение (конкатенация) файлов
```

#### Копирование, перемещение, удаление
```bash
cp file.1 file.2         # копировать file.1 в file.2
mv file.1 file.2         # переименовать (или переместить) file.1 в file.2
mv file.1 file.2 file.3 directory  # переместить несколько файлов в каталог
rm file.1 file.2 file.3  # удалить файлы
```

#### Работа с каталогами
```bash
mkdir namedir            # создать каталог
rmdir dir_1 dir_2        # удалить пустые каталоги
cd <namedir>             # перейти в каталог (без параметров — в домашний)
pwd                      # показать полный путь текущего каталога
```

#### Просмотр содержимого (`ls`)
```bash
ls [опции] [имя]
```
Некоторые опции:

| Опция | Описание |
|-------|----------|
| `-l`  | Подробный список (права, владелец, размер и т.д.) |
| `-a`  | Показать все файлы, включая скрытые (начинающиеся с точки) |
| `-t`  | Сортировка по времени модификации |
| `-r`  | Обратный порядок сортировки |
| `-R`  | Рекурсивный вывод подкаталогов |
| `-i`  | Показать inode (идентификатор) каждого файла |
| `-d`  | Вывести имя каталога, а не его содержимое |
| `-F`  | Добавить `/` к именам каталогов и `*` к исполняемым файлам |

#### Поиск по шаблону (`grep`)
```bash
grep [ключи] "шаблон" файлы
```
Ключи:

| Ключ | Действие |
|------|----------|
| `-v` | Строки, **не** содержащие шаблон |
| `-c` | Только количество строк, где шаблон найден |
| `-i` | Игнорировать регистр букв |
| `-l` | Вывести только имена файлов, содержащих шаблон |
| `-n` | Показать номера строк |
| `-s` | Только код завершения, без сообщений |

**Примеры:**
```bash
# Имена файлов с расширением .txt, содержащих "student"
grep -l student *.txt

# Определить имя пользователя на терминале tty23
who | grep tty23
```

## Ответы на контрольные вопросы

### 1. Что считается файлами в ОС LINUX?

В операционной системе Linux файлами считаются:
- **обычные файлы** (текстовые, бинарные, исполняемые программы, скрипты и т. п.);
- **каталоги** (директории) — специальные файлы, хранящие списки входящих в них объектов;
- **специальные файлы устройств**, представляющие периферийное оборудование (диски, принтеры, терминалы и т. д.); они делятся на байт-ориентированные (символ `c`) и блок-ориентированные (символ `b`);
- **символические ссылки** (`l`) — файлы, содержащие путь к другому файлу;
- **именованные каналы** (FIFO), **сокеты** и другие объекты, которые также представляются в файловой системе как файлы.

Такой подход обеспечивает единообразный доступ ко всем ресурсам: и к данным на диске, и к периферийным устройствам.

### 2. Объясните назначение связей с файлами и способы их создания.

Связи позволяют обращаться к одному и тому же файлу (его содержимому) через разные имена или из разных каталогов. Различают два вида связей:

- **Жёсткая связь (hard link)** — ещё одно имя того же файла, ссылающееся на тот же индексный дескриптор (inode). Оригинал и связь полностью равноправны; файл существует, пока существует хотя бы одна жёсткая ссылка. Создаётся командой:
  ```bash
  ln <исходный_файл> <новая_связь>
  ```
- **Символическая связь (symbolic link, symlink)** — отдельный файл, хранящий путь к целевому файлу. При обращении к такой ссылке система автоматически перенаправляет запрос к оригиналу. Создаётся командой:
  ```bash
  ln -s <целевой_файл> <имя_ссылки>
  ```
  Символические ссылки могут указывать на файлы и каталоги, в том числе на другие файловые системы, а жёсткие — только на файлы в пределах одной файловой системы.

### 3. Что определяет атрибуты файлов и каким образом их можно просмотреть и изменить?

Атрибуты файла определяют:
- **тип файла** (обычный, каталог, ссылка, устройство);
- **права доступа** для владельца, группы и остальных пользователей (чтение `r`, запись `w`, выполнение `x`);
- **владельца** файла и **группу-владельца**;
- **размер** файла, дату и время последней модификации (или изменения метаданных, или доступа);
- **количество жёстких ссылок** на файл.

**Просмотр атрибутов:** основная команда — `ls -l` (подробный список) и её варианты (`ls -la`, `ls -ld` и т. д.).

**Изменение атрибутов:**
- прав доступа — командой `chmod` (в символьном виде, например `chmod u+x,g+r,o-rw file`, или в числовом, например `chmod 754 file`);
- владельца — командой `chown` (требует прав суперпользователя);
- группы — командой `chgrp`;
- временных меток — командой `touch`.

### 4. Какие методы создания и удаления файлов, каталогов Вы знаете?

**Создание файлов:**
- с помощью оператора перенаправления: `> file.txt` или `>> file.txt`;
- командой `touch file.txt` (создаёт пустой файл, если он не существует, или обновляет временные метки);
- копированием существующего файла: `cp source newfile`;
- с помощью текстовых редакторов (`nano`, `vim`, `gedit` и т. п.);
- выводом программ, перенаправленным в файл: `ls > files_list.txt`.

**Удаление файлов:**
- `rm file.txt` — удаление файла;
- `rm -f file.txt` — принудительное удаление без запросов;
- `rm -i file.txt` — удаление с подтверждением.

**Создание каталогов:**
- `mkdir dirname` — создать обычный каталог;
- `mkdir -p path/to/dir` — создать цепочку вложенных каталогов.

**Удаление каталогов:**
- `rmdir dirname` — удаление **пустого** каталога;
- `rm -r dirname` — рекурсивное удаление каталога со всем содержимым;
- `rm -rf dirname` — принудительное рекурсивное удаление (осторожно!).

### 5. В чём заключается поиск по шаблону?

Поиск по шаблону — это поиск строк в одном или нескольких файлах, соответствующих заданному образцу (регулярному выражению или простой подстроке). Основная утилита для такого поиска — `grep`.

Примеры использования:
```bash
grep "шаблон" file.txt           # поиск строк с шаблоном в файле
grep -r "ошибка" /var/log/       # рекурсивный поиск в каталоге
grep -l "ключевое слово" *.txt   # вывод только имён файлов, содержащих шаблон
grep -c "предупреждение" *.log   # подсчёт строк с шаблоном в каждом файле
grep -v "отладка" файл           # строки, НЕ содержащие шаблон
grep -i "error" log.txt          # без учёта регистра
```
Шаблон может быть не только фиксированной строкой, но и регулярным выражением (метасимволы `^`, `$`, `.`, `*`, `[]` и др.). Кроме `grep`, поиск файлов по имени или свойствам осуществляет утилита `find`.

### 6. Какой командой можно получить список работающих пользователей и сохранить его в файле?

Для получения списка работающих в системе пользователей используются:
- `who` — показывает, кто залогинен, с какого терминала и когда;
- `w` — более подробная информация о залогиненных пользователях и их активных процессах;
- `users` — краткий список имён пользователей.

Чтобы сохранить результат в файл, применяется перенаправление вывода:
```bash
who > users_list.txt          # полный список (сохранит в файл)
w >> users_list.txt           # дополнит файл подробной информацией
```
Или, например, получить только уникальные имена пользователей:
```bash
users | tr ' ' '\n' | sort -u > unique_users.txt
```
Команда `who` присутствует в большинстве Linux-систем и хорошо подходит для ответа на вопрос.
